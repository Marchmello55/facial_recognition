# Система распознавания лиц на Python

## Описание проекта

Это приложение для распознавания лиц с возможностью пополнения библиотеки лиц. 
Работает на базе OpenCV и не требует тяжелых зависимостей типа dlib или face_recognition.

## Структура проекта

```
/workspace/
├── main.py              # Главный скрипт с пользовательским интерфейсом
├── face_database.py     # Модуль управления базой данных лиц
├── face_recognizer.py   # Модуль распознавания лиц
└── README.md            # Этот файл
```

## Технические решения

### 1. Архитектура приложения
- **Модульность**: Проект разделен на три независимых модуля по принципу единой ответственности
  - `FaceDatabase` - хранение и управление данными
  - `FaceRecognizer` - логика распознавания
  - `main.py` - пользовательский интерфейс

### 2. Детекция лиц
- Используется **каскад Хаара** из OpenCV (`haarcascade_frontalface_default.xml`)
- Преимущества:
  - Быстрая работа
  - Не требует дополнительных библиотек
  - Работает на CPU без GPU

### 3. Извлечение признаков (Embedding)
Собственная реализация эмбеддинга на основе:
- **Гистограмма интенсивностей** (64 бина) - общая информация о распределении яркости
- **Региональные гистограммы** - изображение делится на 4x4 региона, для каждого считается гистограмма (16 бин)
- **Статистики изображения**: mean, std, min, max, median, 25-й и 75-й перцентили
- Итоговый вектор нормализуется для улучшения сравнения

### 4. Сравнение лиц
- Используется **косинусное сходство** между векторами признаков
- Формула: `cosine_sim = dot(emb1, emb2) / (norm(emb1) * norm(emb2))`
- Порог чувствительности настраивается (по умолчанию 0.35)

### 5. Хранение данных
- Формат: **pickle** для сериализации numpy-массивов
- Структура: словарь с ключами 'faces' (эмбеддинги) и 'names' (имена)
- Автосохранение при каждом изменении

### 6. Оптимизация производительности
- Обработка каждого 2-го кадра (пропуск кадров)
- Кэширование результатов детекции
- Локальное хранение базы данных

## Установка

Проект использует только стандартные библиотеки:
```bash
# Уже установлено в системе
pip install opencv-python numpy
```

## Запуск

```bash
python main.py
```

## Функционал

1. **Распознавание с камеры** - реальное время с веб-камеры
2. **Добавление лица из файла** - загрузка изображения
3. **Просмотр базы** - список всех известных лиц
4. **Удаление лица** - удаление по имени
5. **Очистка базы** - полное удаление всех данных

## Управление в режиме камеры

- **'q'** - выход из режима камеры
- **'a'** - добавить текущее лицо в базу

## Ограничения данной реализации

1. **Точность**: Каскады Хаара и гистограммные эмбеддинги менее точны, чем нейросетевые подходы (face_recognition, ArcFace)
2. **Условия освещения**: Чувствительность к освещению
3. **Угол лица**: Лучше работает с фронтальными лицами
4. **Масштабируемость**: При большой базе (>100 лиц) может замедляться

## Возможности улучшения

Для production-системы рекомендуется:
1. Использовать предобученные нейросети (DNN-модели OpenCV, FaceNet, ArcFace)
2. Добавить аугментацию данных при обучении
3. Реализовать многопоточную обработку
4. Добавить базу данных (SQLite/PostgreSQL) вместо pickle
5. Реализовать REST API для интеграции
