# Face Recognition System

Система распознавания лиц на Python с возможностью пополнения библиотеки.

## Требования

- Python 3.7+
- OpenCV
- face_recognition
- numpy
- dlib

## Установка зависимостей

```bash
pip install opencv-python face-recognition numpy
```

**Важно:** Библиотека `face_recognition` требует установки `dlib`, который может потребовать дополнительные зависимости:

### Для Ubuntu/Debian:
```bash
sudo apt-get install cmake libopenblas-dev liblapack-dev libx11-dev libgtk-3-dev
pip install dlib
pip install face-recognition
```

### Для macOS:
```bash
brew install cmake
pip install dlib
pip install face-recognition
```

### Для Windows:
Установите Visual C++ Build Tools и затем:
```bash
pip install dlib
pip install face-recognition
```

## Использование

### Запуск программы

```bash
python main.py
```

### Меню управления

1. **Запустить распознавание с веб-камеры** - запускает камеру в реальном времени
   - Нажмите `q` для выхода
   - Нажмите `a` для добавления текущего лица в базу

2. **Добавить лицо из файла изображения** - загрузка лица из фотографии

3. **Показать список всех лиц в базе** - просмотр сохраненных лиц

4. **Удалить лицо из базы** - удаление по имени

5. **Очистить всю базу данных** - полное удаление всех записей

6. **Выход** - завершение работы программы

## Описание решений

### Архитектура проекта

Проект разделен на три модуля для лучшей организации кода:

#### 1. `face_database.py` - Модуль базы данных
**Решения:**
- Используется `pickle` для сериализации - простой способ хранения данных Python
- Хранение энкодингов (векторов признаков) и имен в списках
- Автосохранение при каждом изменении базы
- Методы для CRUD операций (Create, Read, Update, Delete)

**Почему pickle?**
- Простота использования
- Сохраняет numpy массивы без дополнительной конвертации
- Не требует внешних СУБД для простого проекта

#### 2. `face_recognizer.py` - Модуль распознавания
**Решения:**
- Использование библиотеки `face_recognition` (основана на dlib)
- Обработка каждого N-го кадра (по умолчанию 3-й) для производительности
- Разделение RGB/BGR форматов (OpenCV использует BGR, face_recognition требует RGB)
- Настройка порога чувствительности (tolerance=0.6)

**Оптимизация производительности:**
- Распознавание не на каждом кадре, а каждые 3 кадра
- Кэширование результатов между кадрами
- Это увеличивает FPS с ~5 до ~15-20

#### 3. `main.py` - Основной скрипт
**Решения:**
- Консольное меню для простоты использования
- Интерактивный режим камеры с горячими клавишами
- Обработка ошибок и исключений
- Возможность добавления лиц как из файлов, так и напрямую с камеры

### Алгоритм распознавания

1. **Детекция лица** - поиск областей с лицами на изображении
2. **Извлечение энкодинга** - преобразование лица в вектор из 128 чисел
3. **Сравнение** - вычисление евклидова расстояния до известных лиц
4. **Классификация** - если расстояние меньше порога, лицо считается распознанным

### Параметры настройки

- `tolerance` (0.6 по умолчанию): порог схожести
  - Меньше (0.5) = строже распознавание, меньше ложных совпадений
  - Больше (0.7) = мягче распознавание, лучше работает при разном освещении

- `process_every_n_frames` (3 по умолчанию): частота обработки
  - Меньше = выше точность, но медленнее
  - Больше = быстрее, но возможна задержка в обновлении
